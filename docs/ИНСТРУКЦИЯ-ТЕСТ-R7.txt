К-7 ИИ — тестовый комплект r7 без отдельного EXE запускника

1. Полностью распакуйте ZIP в обычную папку.
2. Для установки запустите «1. Установить К-7 ИИ.exe».
3. Для Launch Center запустите «2. Запустить К-7 ИИ.cmd».
   CMD открывает Launch Center из того же EXE установщика. Второго EXE,
   который удалял Defender на тестовом ПК, в комплекте нет.
4. Для SingBox HTTP или HTTPS заполните сервер, порт, логин и пароль,
   нажмите «Сохранить и проверить», затем запустите Codex.
5. Кнопка «ОТКРЫТЬ ХРОМ С ПРОКСИ» запускает установленный Google Chrome
   через http://scuf-meta.ru:10894 с отдельным профилем %USERPROFILE%\chrome-proxy.

Администраторские права и исключения Defender не требуются.
Если Defender удалит единственный EXE установщика, нужен скриншот
«Безопасность Windows → Журнал защиты» с точным именем обнаружения.
