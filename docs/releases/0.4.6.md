# K-7 Launcher 0.4.6 Preview

После запуска Codex через SingBox окно Launch Center можно закрыть. Соединение
удерживает отдельный скрытый процесс, который работает до выхода клиента.
Закрытие окна или авария оконного процесса больше не останавливают маршрут.

Кнопки «Остановить маршрут» и «Сбросить маршрут» сохранены. После выхода клиента
выполняется очистка runtime и временного системного proxy. При отказе остановки
программа сообщает, что очистка не подтверждена.

Включено ранее подготовленное исправление запуска Store Codex с идентификатором
пакета. Издание для сотрудников включает Codex и Claude Code; OpenCode исключён
в соответствии с составом общего `main`.

Для обновления нужно завершить Codex и прежние сеансы Launcher, распаковать
комплект 0.4.6 и запустить установщик. Он обновляет установленную копию Launch
Center и ярлыки. Следующие запуски выполняются через обновлённый ярлык.

Канал — Preview, согласованный владельцем. Полная приёмка на чистом рабочем ПК
и проверка настоящего Codex с закрытым окном Launcher не заявляются. Версия не
подтверждает новый допуск Claude и не имеет подписи Authenticode.

Проверки жизненного цикла используют отдельные Windows-процессы и изолированные
ключи реестра; исходники входят в репозиторий. Версия не содержит двоичных
патчей, не переносит учётные данные и не меняет истории или сессии клиентов.
